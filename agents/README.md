# Инструкции для агентов

## Синхронность содержимого

Содержимое файлов в каталоге **`agents/`** нужно поддерживать **согласованным**:

- при добавлении или изменении инструкции здесь проверьте, не противоречит ли она **[AGENTS.md](../AGENTS.md)** в корне и не устарела ли она относительно реальных скриптов и структуры репозитория;
- если меняется процесс (сборка, демо, тесты), обновите и **`agents/`**, и при необходимости **AGENTS.md**, чтобы не оставалось двух разных «истин».

Документация для пользователей:

- **[README.md](../README.md)** (английский) и **[README.ru.md](../README.ru.md)** (русский) должны оставаться **парами одного содержания**: те же разделы, те же факты о плагине; отличается только язык формулировок.
- после изменений в тексте демо или в демо-хранилищах запустите **`npm run demo`** (или отдельно **`npm run demo:screenshots`** для PNG и цепочку **`demo:capture`** + **`demo:render`** для GIF): должны обновиться и английские, и русские материалы (**`obsidian-tests/demo-vault`** и **`obsidian-tests/demo-vault-ru`** — один сценарий на двух языках).
